# Python Quest — Zero to AI Engineer

A beginner-friendly Python learning game by Andy Chum, featuring 10 worlds, 50 lessons, 90 quiz questions, 20 debugging challenges and 40 coding labs. The new practice exercises use fictional tutoring, homework feedback, lesson scheduling, Gmail drafting, IELTS and AI-agent examples.

**Play:** https://andychum.github.io/python-quest/

## How to use

Open the published link, select World 1, read the explanation and try quizzes and coding labs. Use **Show answer & explanation** whenever you need help. Coding labs load Pyodide in the browser and require internet access.

Student names and records in exercises are fictional. Progress is saved locally in your browser.

## Intermediate reading

Each world has a worked example, a reading question and a coding lab. Predict the output, trace the values, then run the code and explain the result. Start with Python fundamentals and work up to the model-routing capstone. The AI examples use fictional models and data. At the end, try tracing and modifying an unfamiliar script without revealing the answer.

## Hosting

GitHub Pages is deployed from the `main` branch using the workflow in `.github/workflows/pages.yml`. Under repository Settings → Pages choose **GitHub Actions** as the build and deployment source if the deployment is not automatically enabled.
