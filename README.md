# Python Quest

[Play Python Quest](https://andychum.github.io/python-quest/)

Python Quest teaches you to read and understand Python used in tutoring, scheduling, data and AI workflows. Each of the 10 worlds starts with two concepts and worked examples, followed by four multiple-choice questions. Every option gives its own feedback and can be retried.

The practice scenarios and models are fictional. The game needs no API keys, accounts or Python installation. Reading progress is stored in the browser.

## Hosting

GitHub Pages uses the GitHub Actions workflow in `.github/workflows/pages.yml`. The static site contains `index.html`, `reading.js` and `game.js`. To preview locally, serve the repository with `python -m http.server` and open the local address.
